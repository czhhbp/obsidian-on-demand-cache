# On-Demand Cache（按需缓存）

按需持久缓存网络附件（图片、视频、音频、文档等）。打开笔记时才下载，渲染时透明地使用本地副本而非网络文件，同时保持笔记中的原始链接不变。

[English documentation / 英文文档](README.md)

## 核心原理

- **文档内容不变**：笔记中的网络链接（`https://...`）始终保持原样，同步时只同步链接文本，不同步具体文件。
- **随用随下载**：打开笔记时才下载其中的网络附件，不主动批量下载。
- **本地持久缓存**：附件下载到 `.cache` 目录（已排除同步，不会被同步）。
- **渲染时用本地文件**：阅读/预览时，自动将网络链接替换为本地缓存文件路径，实现离线访问。
- **多设备自动补缓存**：在其他设备打开笔记时，若本地没有缓存，自动下载。

## 与"下载并替换链接"类插件的区别

大多数同类插件会**永久改写**笔记中的链接（把 `https://...` 改成本地路径）。本插件**从不修改笔记内容**，只在渲染时临时用本地文件，原文始终保留网络链接。因此：

- 笔记可安全跨设备同步（只同步链接文本，不同步大文件）。
- 换设备后自动按需补缓存。
- 随时可回退到网络加载，无副作用。

## 实现原理

### 关键处理步骤

1. **链接提取**：打开笔记时，用正则从 Markdown 内容中提取所有网络链接，支持 Markdown 图片 `![alt](url)`、Markdown 链接 `[text](url)`、HTML 标签 `<img>`/`<audio>`/`<video>`/`<source>` 以及裸 URL。

2. **缓存判断**：对每个链接判断是否应缓存——是否已缓存、是否有文件后缀、是否符合白名单/黑名单、是否超过大小限制。

3. **下载与去重**：通过 `requestUrl` 下载文件，计算内容哈希去重（相同内容只存一份），写入 `.cache` 目录，并更新缓存索引 `cache-index.json`。

4. **渲染替换**：通过 Markdown 后处理器 + 全局 `MutationObserver` 双重机制，在渲染时将 `<img>` 等标签的 `src` 从网络链接替换为本地 `app://` 资源路径（`getResourcePath`），实现离线显示。

5. **清理**：启动时扫描所有笔记，删除未被任何笔记引用的缓存文件。

### 关键设计

- **缓存目录可以是隐藏目录**：`FileSystemAdapter.getResourcePath` 会把磁盘绝对路径直接编码进 `app://` 资源代理 URL，Obsidian 渲染层据此从磁盘读取文件，不依赖 vault 的文件索引，因此 `.cache` 这类隐藏目录同样可用。默认即使用 `.cache`。
- **渲染替换不修改原文**：替换只发生在渲染层的 DOM 上，笔记文件内容始终不变。

## 安装

本插件已在 Obsidian 社区插件商店上架。

**从商店安装（推荐）：**

1. 打开 Obsidian → 设置 → 社区插件 → 浏览。
2. 搜索 "On-Demand Cache"，点击安装，然后启用。

**手动安装：**

1. 从[最新 Release](https://github.com/czhhbp/obsidian-on-demand-cache/releases) 下载 `main.js` 和 `manifest.json`。
2. 将两个文件放入 Vault 中的 `.obsidian/plugins/on-demand-cache/` 目录。
3. 在 Obsidian → 设置 → 社区插件 → 已安装插件中启用 "On-Demand Cache"。

## 使用方法

### 自动缓存（默认行为）

**打开笔记时自动缓存**：当你打开一篇包含网络附件的笔记时，插件会自动下载其中的附件到本地缓存。之后即使断网，也能正常显示。

> ⚠️ **重要**：缓存**只在打开笔记时触发**。如果你在**编辑状态下**新插入一个网络附件（例如粘贴一张网络图片链接），插件**不会**立即缓存它。你需要**重新打开该笔记**（或切换到其他笔记再切回来），插件才会检测并缓存新插入的附件。

### 命令

- **缓存所有文档中的网络附件**：遍历所有 Markdown 文档并缓存。
- **缓存当前文档中的网络附件**：只缓存当前打开的文档。
- **清理未使用的缓存文件**：删除未被引用的缓存。

### 设置面板

在 Obsidian 设置 → 社区插件 → On-Demand Cache 中可配置（界面语言随 Obsidian 自动切换中英文）：

| 设置项 | 说明 |
|--------|------|
| 文件类别过滤模式 | 白名单 / 黑名单 |
| 文件后缀列表 | 逗号分隔，如 `png,jpg,mp4,pdf,docx` |
| 单个附件最大大小 | 单位 MB，0 表示不限制 |
| 缓存目录 | 默认 `.cache` |
| 启动时自动清理 | 开关 |
| 渲染时使用缓存 | 开关 |
| 诊断日志 | 排查问题时开启，默认关闭 |

## 缓存目录说明

缓存文件存放在 `.cache` 目录。该目录应**排除同步**，确保具体文件不会被上传：

- **Git**：将 `.cache/` 加入 `.gitignore`。
- **其他同步方案**（Obsidian Sync、Dropbox、OneDrive 等）：为 `.cache/` 目录配置对应的排除/忽略规则。

> 注意：缓存目录**可以**以 `.` 开头（隐藏目录）。由于 `app://` 资源路径直接由磁盘解析、不经 vault 索引，像 `.cache` 这样的隐藏目录也能正常加载图片。

## 支持的链接形式

- Markdown 图片：`![alt](https://...)`
- Markdown 链接：`[text](https://...)`
- Obsidian wiki 链接：`![[https://...]]`、`[[https://...]]`、`[[https://...|别名]]`
- HTML 标签：`<img src="https://...">`、`<audio>`、`<video>`、`<source>`
- 裸 URL：`https://...`
